# Study Guide — Bookstore E-commerce

What to **study before** building each epic. For every epic there is one document
listing the concepts you need, a short explanation of why they matter *for that
increment*, and free resources to learn them (W3Schools as the beginner-friendly tutorial,
MDN as the authoritative reference).

How to use it: read the topics for the epic, then open that epic's
[backlog](../backlog/README.md) file and build its user stories. Each epic lists
**only** what that increment needs —
no concept from a later epic appears before you reach it.
