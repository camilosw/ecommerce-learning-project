# Epic 3 — Product listing

> Part of the [Backlog](README.md) · Study guide _pending_ · Tag `epic-3-product-list`

The catalog stops being hard-coded HTML: a MariaDB schema holds the books, and PHP reads
them through PDO with prepared statements.

> Stories are outlined. **Acceptance criteria are written when the epic is planned**, as
> part of the PM scope confirmation, before any code is generated.

- **E3-1** — As a customer, I want to see the book catalog loaded from the database so that I can browse the real, up-to-date offer.
- **E3-2** — As a customer, I want to see the full catalog on a dedicated page so that I can explore all books.
- **E3-3** — As a customer, I want to see the available categories so that I know what types of books are sold.
- **E3-4** — As a customer, I want to filter books by category so that I can find what I'm looking for faster.
