# Epic 5 — Login

> Part of the [Backlog](README.md) · Study guide _pending_ · Tag `epic-5-login`

Sessions, hashed passwords, and an area of the site that only an authenticated
administrator can reach. Epic 8 reuses this login to protect the admin panel.

> Stories are outlined. **Acceptance criteria are written when the epic is planned**, as
> part of the PM scope confirmation, before any code is generated.

- **E5-1** — As an administrator, I want to log in so that I can access the management area.
- **E5-2** — As an administrator, I want protected pages to be accessible only after logging in so that no one else can reach them.
- **E5-3** — As an administrator, I want to log out so that I can protect access when I am done.
